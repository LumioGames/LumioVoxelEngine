# 0007 · 采用 LGE-V1.4 作为实现基线

- 日期:2026-08-27
- 状态:生效

## 背景

仓内规范入口、模块地图与仓库边界文档仍把当前基线写成上一版架构镜像，而 `LumioGameEngineArchitecture` 已发布 `LGE-V1.4-2026-08-27`。该基线把 Voxel 族 ADR-024/025/035/036 收口为正式契约，并新增 ADR-038 状态机描述符。V1.3 输入设计包只用于需求提取，其中 persistence / runtime / ffi / common 等 crate 划分与仓内 [0006](0006-crate-map.md) 冲突，不得落地。

[0001](0001-snapshotcut-vs-capture-ref.md)–[0006](0006-crate-map.md) 仍然有效，本条只改「当前实现基线」指针，不改写既有决策正文。

## 决策

- 本仓当前实现基线是 `LGE-V1.4-2026-08-27`；只读镜像是 [`docs/architecture/LumioGameEngine_Architecture_v1.4.md`](../../docs/architecture/LumioGameEngine_Architecture_v1.4.md)。
- 物理 crate 仍只允许 [0006](0006-crate-map.md) 的七个：`lumio-voxel-contracts`、`lumio-voxel-domain`、`lumio-voxel-ops`、`lumio-voxel-world`、`lumio-voxel-project`、`lumio-voxel-migration`、`lumio-voxel-test-support`。
- Query / Mutation 落在 `lumio-voxel-ops`；L2 `ReadView` / `WriteSet` / `CommitBatch` / Availability / Storage Port 落在 `lumio-voxel-domain`。
- 不得创建 persistence、runtime、ffi 或 common crate；不得手写第二套 Schema 字段、错误码或 Serializer。
- V1.3 输入设计包只作历史来源；与 V1.4 或 0006 冲突的 crate、字段和依赖方向无效。其 Hash 输入文件不得修改。
- 十个逻辑模块的稳定方法名、crate-private 接口、失败语义与后续卡互斥文件集以 [`docs/plans/lve-v1.4-implementation-blueprint.md`](../../docs/plans/lve-v1.4-implementation-blueprint.md) 为准。
- VOX-D-001–008 数值与后端选择仍保持 unapproved，本条不冻结默认值。

## 后果

Foundation 与后续实现卡按 V1.4 镜像、本条和蓝图落地。ADR 索引由本条所属架构卡维护；根 Cargo / crate 入口仍由后续工程卡创建。知识导航若需登记新文档，只提交增量说明，不在本条改写索引。
